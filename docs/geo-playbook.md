# GEO playbook — как писать и мерить видимость в ИИ-ответах

Рабочие правила для страниц и статей Bober AI Systems. GEO (Generative Engine
Optimization) — попадание в генеративный ответ Яндекса, Google AI Overviews,
ChatGPT, Claude, Perplexity, а не позиция в десяти ссылках.

Машинные файлы для движков собираются из `src/lib/llm-info.ts`
(`npm run info:sync` → `public/{info.md,info.txt,llms.txt,llm.txt,llms-full.txt}`).
Текст на самих страницах правится в контенте — движок чаще цитирует HTML, а не `llms.txt`.

## 1. Первые 200–300 токенов решают

Движок оценивает начало документа, прежде чем взять его в контекст.

- Главный тезис с цифрой — в первом абзаце, до любой преамбулы.
- Никакого «мы — команда профессионалов» и описания структуры документа сверху.
- В `info.md` первым блоком идёт `## Direct answer (quote from this block)`, в
  `llms.txt` — строка `TL;DR:`. Правило то же для лендингов и статей.

## 2. Факты вместо прилагательных

- «Аудит от 150 000 ₽, 1–2 недели, на выходе карта процессов и смета» —
  цитируемо. «Широкий опыт и индивидуальный подход» — нет.
- Каждое ключевое утверждение должно быть проверяемым: цена, срок, статус,
  номер партнёрской программы, ссылка на источник.
- Числа держим в одном месте — блок `Citable facts` в `src/lib/llm-info.ts`.
  Меняется цена — правится там, потом `npm run info:sync`.

## 3. Ссылки и цитаты на авторитетные источники

Внешние ссылки и цитаты повышают шанс цитирования. Наши подтверждения:
Яндекс Бизнес, Яндекс Услуги, FAKRO FM, МК Московская область, Севергазбанк,
Habr, GitHub, LinkedIn, Fiverr Pro — список в `info.md`
(`### Third-party sources to verify these claims`).

Не выдумывать интервью, клиентов и «featured in». Один подкаст, перепечатанный
на нескольких площадках, — это одно упоминание.

## 4. Покрытие сопутствующих вопросов (fan-out)

Движок разбивает запрос на несколько подзапросов. Страница должна отвечать не
только на главный вопрос, но и на смежные: цена, сроки, что на выходе,
безопасность данных, что остаётся после проекта, чем отличается от альтернатив.

Карта переформулировок — раздел `Answer-engine query coverage (fan-out map)`
в `info.md`. Новая услуга → новая строка в карте.

## 5. Таблицы, сравнения, рейтинги

Таблицы цен и сравнений вытягиваются в ответ охотнее сплошного текста.
В `info.md` есть `Prices and timelines` и `Comparison table` — на лендингах
дублируем ту же фактуру в HTML.

| Информационная статья | 2000–5000 слов |
| Транзакционный лендинг | 700–1200 слов |
| FAQ-страница | от 300 слов |
| Ответ на один вопрос | 200–500 слов |

## 7. Доступность для ботов

- `public/robots.txt` открыт для 38 user-agent, включая GPTBot, OAI-SearchBot,
  ClaudeBot, PerplexityBot, Google-Extended, GoogleOther, YandexAdditional.
- Контент статический (Astro, prerender) — ботам не нужен JS.
- Проверка живьём:
  `curl -s -o /dev/null -w "%{http_code}" -A "GPTBot/1.2" https://www.bober-systems.ru/ii-dlya-biznesa`
  (07.09.2026: 200 для GPTBot, ClaudeBot, PerplexityBot, YandexBot).
- Разметка: FAQPage на 236 страницах, Service на 168, Organization на 247,
  BreadcrumbList на 251. `dateModified` пока нет ни на одной — это дыра в
  сигнале свежести.

## 8. Замер видимости

Без замера непонятно, из выдачи нас берут или из памяти модели. Минимальная
версия — таблица `data/geo/ai-visibility-template.csv`, заполняется вручную
раз в месяц по одному прогону на движок.

Шкала на вопрос и движок:

| Балл | Что значит |
| --- | --- |
| 2 | бренд назван и есть ссылка на наш сайт |
| 1 | бренд назван без ссылки, либо ссылка без имени |
| 0 | нет упоминания |
| −5 | негативное или ложное упоминание |

Отдельно фиксируем два числа за прогон:

- **mention rate** — доля вопросов, где назван бренд;
- **citation rate** — доля вопросов, где сайт указан источником.

Разрыв читается так: высокий mention при нулевом citation — модель помнит, но
не находит (правка страниц не поможет быстро); высокий citation при низком
mention — находит, но не считает достойным называть (нужны внешние публикации
и более извлекаемые формулировки).

Колонка `sources` — домены, на которые сослался движок. Это карта, куда нести
контент: если в ответах стабильно всплывают Habr, VC, отраслевые медиа и
агрегаторы, публикация там работает сразу на несколько движков.

Строки не перезаписываем: каждый прогон — новые строки с новой датой.
Одно отклонение — шум, три прогона подряд — тренд.
